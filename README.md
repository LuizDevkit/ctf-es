# CTF-ES — Plataforma Offline com 101 Desafios

Plataforma CTF desenvolvida para estudos OFFLINE de segurança ofensiva. Ideal para laboratórios de faculdade, CTFs internos e hackathons sem internet.

**Como funciona offline:**
Todo usuário roda no próprio PC. Não envia dados pra internet, não precisa de servidor externo.

**Como rodar:**
1. Baixe o repositório
2. Dê duplo clique em `iniciar-CTF.bat`
   OU rode: `python server.py`
3. Abra http://localhost:5000

**Stack:** Python (Flask) + HTML/CSS/JS + JSON local
**Desafios:** 101 (Web, Crypto, Forense, OSINT, Reverso) - Fácil 🟢 / Médio 🟡 / Avançado 🔴
**Formato da flag:** CTF-BR{...}
